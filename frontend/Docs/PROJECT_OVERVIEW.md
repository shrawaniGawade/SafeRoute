# SafeRoute – AI-Powered Safety-Aware Route Recommendation System

## 1. Project Overview
SafeRoute is an AI-powered project that aims to recommend safer routes by considering safety-related factors instead of focusing only on the shortest distance.

## 2. Problem Statement
Traditional navigation systems mainly focus on the shortest or fastest route. SafeRoute aims to consider additional safety factors to help users make more informed route choices.

## 3. Objectives
- Calculate a route safety score.
- Consider street lighting, crime risk, accident risk, and crowd level.
- Develop a user-friendly web application.
- Integrate a frontend, backend API, and machine learning model.

## 4. Technologies Used
- Frontend: React, TypeScript, Vite
- Backend: Node.js, Express, TypeScript
- AI Service: Python, FastAPI
- Machine Learning: Scikit-learn, Random Forest

## 5. Current Progress
The basic frontend, backend API, and AI model are connected. The application can generate and display a demonstration safety score.

## 6. Limitations
The current model uses synthetic demonstration data. Its scores have not been validated against real-world safety data.
